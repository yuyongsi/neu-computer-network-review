# NEU 计算机网络复习

东北大学计算机网络离线刷题本，适合按章节练习、复盘错题和模拟历年试卷。题库按原卷页码保留来源；题面缺损、答案歧义和待核对内容会明确标出。

## 快速开始

1. 下载或克隆本仓库，并保留整个目录结构。
2. 双击 `index.html`，使用 Edge 或 Chrome 打开。
3. 不需要安装依赖、登录账号或联网。题目与图示从本地文件加载。

## 主要功能

- 按章节、题型、试卷、掌握状态和关键词筛题。
- 选择、判断及明确答案的填空题自动判分；简答与计算题可自评。
- 收藏、个人笔记、错题本、练习记录和本地备份导入导出。
- 历年试卷模拟、计时交卷、扫描原页对照及题图放大。

## 仓库内容

- `index.html`、`app.js`、`styles.css`：离线刷题界面。
- `questions.js`：网页直接加载的题库。
- `题库数据.json`：便于校对和后续编辑的结构化题库。
- `题库核对记录.txt`：扫描版56页逐页核对与缺损说明。
- `assets/pages/`、`assets/figures/`：原卷对照页和重绘题图。
- `打印用/`：配套的打印版讲义、题型方法与答题模板。
- `使用说明.txt`：完整操作说明、题库范围和本地验收记录。

当前题库含452个练习条目，覆盖10组试卷与试题资料。题目不完整或答案存在歧义时会保留说明；请结合课程课件和教师要求核对，不把旧卷答案视为当前考试标准。

## 学习记录与隐私

作答记录、收藏、笔记和错题保存在当前浏览器的本地存储中，不会由本应用自动上传。换浏览器或清理数据前，请在应用内导出备份。导出的个人学习记录不要提交到 GitHub。

本仓库按私有学习资料整理，包含扫描试卷页及手写内容；如要公开仓库，请先确认资料的发布权限并检查扫描页中的个人信息。

## 维护提示

网页使用相对路径加载文件。移动、删改或单独复制 `index.html` 可能导致题库或图片无法显示。修改题库时请同步维护 `questions.js`、`题库数据.json` 和核对记录。
